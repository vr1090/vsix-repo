# vsix-repo

Collection of reusable VSIX packages.

## Available plugins

- [ms-python.python-2026.4.0.vsix](ms-python.python-2026.4.0.vsix)
	Python extension for VS Code with IntelliSense, debugging, environment management, test discovery, and notebook support.
- [esbenp.prettier-vscode-12.4.0.vsix](esbenp.prettier-vscode-12.4.0.vsix)
	Prettier code formatter integration that auto-formats JavaScript, TypeScript, JSON, Markdown, and more.
- [hediet.vscode-drawio-1.6.6.vsix](hediet.vscode-drawio-1.6.6.vsix)
	Draw.io integration for creating and editing flowcharts, architecture diagrams, and UML directly in VS Code.
- [pomdtr.excalidraw-editor-3.9.0.vsix](pomdtr.excalidraw-editor-3.9.0.vsix)
	Excalidraw editor support for hand-drawn style diagrams and visual notes inside the editor.
- [ms-mssql.mssql-1.9.0.vsix](ms-mssql.mssql-1.9.0.vsix)
	Microsoft SQL extension for connecting to SQL Server and Azure SQL, running queries, and viewing results.
- [markmap.vsix](markmap.vsix)
	Markmap plugin for turning Markdown content into interactive mind maps.
- [vscode-animation](vscode-animations.vsix)
	vscode animation
- [c# extension vs code](csharp.vsix) C# extension vs code

- [c# dev kit ](csdevkit.vsix)
	C# dev kit
